Пример генерации данных:
```bash
uv run generate_load_data.py \
--users 30 \
--bands "2600:2:40,1800:2:15" \
--initial-shares "2600_1:90,1800_1:80,2600_2:10,1800_2:20"
```

Пример работы алгоритма:
```bash
uv run load_balancing_scipy.py \
--group-counts "2600_1:2,1800_1:7,1800_2:2,2600_1+1800_1:11,2600_1+1800_2:4,1800_1+2600_2:3" \
--below-threshold "2600_1:1"
```

Большинство сценариев обрабатываются быстро, но есть такие, для которых нужно много времени.
Пример такого (возможно нереалистичного) сценария (работает 1.5-2 минуты):
```bash
uv run python generate_load_data.py --users 100000 --initial-shares "2600:10,2100:5,1800:5,900:65,800:15"

uv run python load_balancing_scipy.py \
  --group-counts "$(uv run python generate_stress_groups.py)"
```
В этом сценарии для 100 000 абонентов и 15 сот (3 сектора, в каждом по 5 диапазонов) получаются:
- 1 023 группы
- 3 825 подбираемых коэффициентов
- Размеры групп от 1 до 29 694 UE
- Неустранимая перегрузка первых сот каждого диапазона
- Много коэффициентов, близких к границам: 2 789 около нуля и 984 около единицы
